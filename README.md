# Email Summarizer using AI

This project uses AI to summarize the content of emails automatically. It extracts key points and provides a concise summary to help users quickly understand long email threads.

## Features

- Reads and processes latest emails 
- Uses AI to generate summaries
- Cron job support for scheduled summarization (configure it as per your system and preference)

## Getting Started

1. Clone the repo
2. Set up your environment
3. Add your `Credentials.json`, `token.json`, and `.env` file (these are ignored in Git).
   here Credentials.json contains OAuth token of your Gmail, and .env will have openAI's API key
